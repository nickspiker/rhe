# Sidecar excludes for brief assignment.
#
# Words listed under an active category section are auto-`#`'d in
# `data/brief_candidates.txt` with reason `excluded: <category>`. The
# auto-exclusion fires before the greedy brief assignment, so excluded
# words don't claim chord slots — those slots go to the next-ranked
# words instead.
#
# Format:
#   [category_name]      ← active section header (auto-exclude applies)
#   #[category_name]     ← disabled section (entire category ignored)
#   word                 ← one word per line; lowercase
#   # comment            ← regular comments, ignored by the parser
#
# Per-word override: NOT supported via this file. To opt back in to a
# single word, remove it from this file (or move it to a disabled
# section). To opt back in to a whole category, comment out the
# section header (`#[gender]`).
#
# Categorization is one editor's judgment — adjust freely. The goal is
# a default that's free of statehood / religious / racial / gender bias
# and proper-noun clutter, with each install free to opt back in.
